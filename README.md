# AtiSunya Infratech — Real Estate Website

React (Vite) site for AtiSunya Infratech.

## Run locally

```
npm install
npm run dev
```

Then open the printed local URL (usually http://localhost:5173).

## Build for production

```
npm run build
```

Output is written to `dist/`.

## Structure

```
src/
├── components/
│   ├── Navbar.jsx / Navbar.css
│   ├── Logo.jsx
│   ├── Hero.jsx / Hero.css
│   ├── About.jsx / About.css
│   ├── Projects.jsx / Projects.css      (Top Projects carousel)
│   ├── Services.jsx / Services.css
│   ├── WhyChooseUs.jsx / WhyChooseUs.css
│   ├── CtaBanner.jsx / CtaBanner.css    (Start Your Journey banner)
│   ├── ContactForm.jsx / ContactForm.css
│   ├── Footer.jsx / Footer.css
│   └── FloatingButtons.jsx / .css       (WhatsApp + scroll-to-top)
├── App.jsx
├── main.jsx
└── index.css                             (design tokens / CSS variables)
```

Images are placeholder stock photos from Unsplash — swap the URLs in each
component with the client's real photography when available.
